# dotMind by Reza Alami — Design System & Decisions

## Brand: dotMind (decided October 2026)

Studio name **dotMind**, domain `dotmind.de`. dotMind leads from day one; „by Reza Alami" is the endorsement. Files: `public/brand/`, regenerated by `scripts/brand/build-logo.cjs`.

### Logotype

- **Wordmark „dotMind"** in Geist SemiBold, outlined to paths, tracking −0.035em, camel-case M so the two words read without a space.
- **The one brand move:** the tittle of the i is an ember circle, slightly wider than the stem and set a little higher than a normal dot. The name says „dot"; the logo shows the dot exactly once, on the i of „Mind": a spark, an idea, a point of focus. No other letter is coloured or altered.
- **Mark „d."** for app icon, social avatar and OG corner: the d from the wordmark plus the ember dot as a full stop, on a rounded ink tile. It reads „d-dot" = dot. Dot and gap derive from the d's stem (dot 1.8 × stem, gap 0.5 × stem); the dot overshoots the baseline like the bowl, and the group sits 1.2 % above the tile's centre (optical centre).
- **Small cut „d."** for the favicon and anything shown at 16–32 px: Geist Bold, larger on the tile, every edge snapped to the 16 px grid (stem 2 px, gap 1 px, dot 4 px), so the dot never merges with the stem in a browser tab. Never use it above 64 px.
- **Logo motion:** only the dot moves, never the letters. *Intro* (header on first load, coming-soon): the dot drops onto the i, squashes on contact and settles, 0.9 s after a 0.25 s delay. *Spark* (hover/focus on the logo link): the dot flares to 1.4× and an ember ring leaves it, 0.45 s. *Thinking* (`.dot-breathe`, form submit): the dot breathes on a 1.2 s loop instead of a spinner. Transform/opacity only; all three are off under reduced motion. Classes in `globals.css` (`logo-fall`, `logo-dot`, `logo-ring`), `<Logo intro />` turns the drop on.
- **Endorsement** „BY REZA ALAMI" in Geist Mono Regular, uppercase, +0.12em: the same voice as the site's `t-label`, so the lockup belongs to the design system instead of sitting on top of it.

### Rules

- **Clear space:** at least the height of the „o" (x-height) on every side.
- **Minimum size:** wordmark 72 px wide on screen (18 mm in print); lockups 160 px wide so the endorsement stays ≥ 10 px; mark 64 px (below that, the small cut down to 16 px).
- **Spelling in running text:** „dotMind", never „Dotmind", „DotMind", „dot mind" or „DOTMIND". The domain stays lowercase: `dotmind.de`.
- **Don't:** recolour letters ember, add a second dot or a period after the name, put the wordmark on photos without an ink or paper panel, stretch, outline, add shadows or gradients, rebuild the logo from live text, or use the endorsement without the wordmark.

## Identity

**Premium dark cinematic · editorial typography · quiet futuristic micro-interactions.**
Warm "tungsten" accent on near-black evokes film light rather than neon.

## Spacing, grid & breakpoints

- 4px base; section rhythm `py-28 md:py-40` (spacious density 3/10).
- Shell: `max-w-[1600px]`, gutters 20 → 32 → 48px.
- Grid: 4 cols (mobile) → 8 (md) → 12 (lg), gap 16/24px. Asymmetric column spans for editorial layouts.
- Breakpoints (Tailwind default): 640 / 768 / 1024 / 1280 / 1536. Tested at 375, 768, 1440.
- Z-scale: content 0 · nav 50 · menu 60 · grain 90 · cursor 100 · skip-link 110.

## Components

Buttons: pill (the only rounded element), primary = bone fill with ember wipe; ghost = hairline. Cards: square corners, hairline dividers — no card boxes. Images: 2px radius, strong 16:10 crops.

## Motion tokens (`src/lib/motion.ts`)

| Token | Value |
| --- | --- |
| `ease.out` | `cubic-bezier(0.22, 1, 0.36, 1)` — arrivals |
| `ease.in` | `cubic-bezier(0.55, 0, 1, 0.45)` — exits |
| `duration` | fast 0.2s · base 0.45s · slow 0.8s · reveal 1s |
| `stagger` | words 35ms · items 80ms |
| `spring.magnetic` | stiffness 180, damping 16 |

Rules: every animation has a job (hierarchy, attention, continuity, feedback). Transform/opacity only. Native scroll — no scroll-jacking, no pinning. Hero text and page transitions use CSS keyframes so they run before hydration (better LCP).

**Reduced motion:** `MotionConfig reducedMotion="user"` drops transforms; custom cursor, magnetic pull, parallax and scroll-scrubbed effects are disabled; the hero field renders a single static frame; CSS keyframes are removed.

## AI design layer

AI is the core of the positioning ("Built for the age of AI"), so it is expressed through the interface itself — always in the same ember accent, never as neon or sci-fi decoration.

| Element | Where | Idea |
| --- | --- | --- |
| **Neural field** (`HeroField`) | Hero background | Grid nodes near the cursor activate and link into a small neural mesh; signal pulses travel along grid lines like data through a network. 2D canvas, paused off-screen. |
| **Decode text** (`ScrambleText`) | "AI Specialist" role | Characters resolve out of machine glyphs, like model output. Width reserved — no layout shift. |
| **Token stream** (`TokenStream`) | Intelligence section statement | Words stream in with a blinking caret, the way a language model writes. |
| **Neural diagram** (`NeuralDiagram`) | Intelligence section | AI core wired to Design, Development, Marketing and Smart Home; the active domain's edge lights up and carries faster signals. Cycles in view; hover takes over. |
| **Sparkle + sheen** (`AiBadge`, `.ai-gradient-text`) | AI projects, AI expertise row, timeline, tech group, headlines | One consistent marker for "this is AI work". |

All of these render their final, readable state under reduced motion.
